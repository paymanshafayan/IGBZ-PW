# `_bin/` — باینری‌هایی که باید دستی آپلود شوند

این پوشه یک دلیل دارد: **سندباکس توسعه به فایل‌های ریلیز گیت‌هاب دسترسی ندارد**
(`objects.githubusercontent.com` → بسته). کد را می‌شود کلون کرد و بستهٔ npm را می‌شود نصب
کرد، ولی باینری آماده نه. پس هر باینری‌ای که لازم داریم باید داخل خود مخزن باشد.

دقیقاً همان الگویی که `_devenv/` برای زیپ وردپرس و ووکامرس دارد و ماه‌هاست جواب می‌دهد.

---

## چه چیزی اینجا بگذارید

### ۱. پنجرهٔ دسکتاپ — یکی از این دو (ضروری)

**گزینهٔ الف — Neutralinojs (سبک، توصیهٔ من برای شروع)**

حدود ۵ مگابایت، یک فایل، بدون دردسر:

```
https://github.com/neutralinojs/neutralinojs/releases
→ neutralinojs-v<version>.zip
```

اینجا بگذارید با همین نام: `_bin/neutralinojs-v<version>.zip`

**گزینهٔ ب — Electron (سنگین‌تر، پخته‌تر و استانداردتر)**

```
https://github.com/electron/electron/releases/download/v43.4.0/electron-v43.4.0-linux-x64.zip
```

حجمش حدود ۱۲۰ مگابایت است و **گیت‌هاب فایل بالای ۱۰۰MB را رد می‌کند**، پس اول تکه‌اش کنید:

```bash
split -b 45m electron-v43.4.0-linux-x64.zip electron-v43.4.0-linux-x64.zip.part-
```

سه فایل به‌دست می‌آید (`…part-aa`, `…part-ab`, `…part-ac`) — **هر سه** را اینجا بگذارید.
`setup.sh` خودش با `cat` سرهمشان می‌کند.

> ⚠️ **آرشیو چندجلدی rar نفرستید** (`part1.rar`, `part2.rar`). ابزار rar ای که در دسترس من
> است جلدها را به هم وصل نمی‌کند. `split` روی فایل اصلی، مطمئن‌ترین راه است.

### ۲. Bun — فقط اگر فورک OpenCode را انتخاب کنید

حدود ۳۵ مگابایت، یک فایل، نیازی به تکه‌کردن ندارد:

```
https://github.com/oven-sh/bun/releases/download/bun-v1.3.14/bun-linux-x64.zip
```

## نکته‌ها

- **معماری مهم است:** نسخهٔ **linux-x64** لازم است، نه ویندوز. سندباکس لینوکس است.
  نسخهٔ ویندوزِ برنامه را بعداً روی دستگاه خودتان با یک دستور می‌سازیم — اینترنت شما باز است.
- **فرمت مهم نیست:** هم `.zip` هم `.rar` باز می‌شود (rar با یک کتابخانهٔ WASM، تست شده).
  ولی برای فایل‌های بزرگ، `split` روی زیپ اصلی از rar بهتر است.
- **کد منبع نفرستید:** مخزن‌های گیت‌هاب را خودم کلون می‌کنم؛ `github.com` و `codeload` باز است.
- این پوشه **عمداً از `.gitignore` مستثنا شده** تا با اینکه `*.zip` نادیده گرفته می‌شود،
  محتوای اینجا کامیت شود.
