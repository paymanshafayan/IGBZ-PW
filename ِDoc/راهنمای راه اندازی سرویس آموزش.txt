تبدیل یا توسعه پلتفرم فروشگاه‌ساز به یک سیستم مدیریت یادگیری (LMS - Learning Management System) به همراه اپلیکیشن موبایل، یک بازار بسیار پرسود (فروش دوره‌های آموزشی) را برای کاربران شما باز می‌کند.
بزرگ‌ترین دغدغه در پلتفرم‌های آموزشی، جلوگیری از دانلود غیرمجاز و پخش شدن ویدیوها (Video Piracy) است. از آنجا که شما هم وب‌سایت (ناپ‌کامرس) و هم اپلیکیشن اختصاصی دارید، دست شما برای اعمال محدودیت‌های سخت‌گیرانه بسیار باز است.
در ادامه، راهکارهای فنی و زیرساختی برای راه‌اندازی این بخش و محافظت از ویدیوها را بررسی می‌کنیم:
------------------------------
## ۱. زیرساخت میزبانی ویدیو (Video Hosting) و جلوگیری از دانلود
هرگز نباید ویدیوهای آموزشی را مستقیم روی سرور ناپ‌کامرس آپلود کنید؛ چون هم سرور کند می‌شود و هم دانلود آن با ابزارهایی مثل IDM بسیار راحت است. باید از سرویس‌های VOD (Video on Demand) تخصصی ایرانی که دارای API هستند استفاده کنید:

* سرویس کاوه نگار (بخش کات) / آپارات کست / آروان کلاد (ArvanCloud VOD):
این سرویس‌ها مجهز به فناوری HLS (HTTP Live Streaming) هستند. در این روش، ویدیو به تکه‌های چند ثانیه‌ای (فایل‌های بسیار کوچک .ts) تبدیل و رمزگذاری (Encrypt) می‌شود. خریدار دوره نمی‌تواند یک فایل یکجای MP4 برای دانلود پیدا کند.
* سرویس ویدیوپک (VideoPack) یا نگارفیلم: این سرویس‌ها به طور اختصاصی برای پلتفرم‌های آموزشی ساخته شده‌اند و بالاترین سطح امنیت ویدیو را در ایران دارند.

## ۲. راهکارهای امنیتی اختصاصی در وب‌سایت (ناپ‌کامرس)
برای بخش وب‌سایت، شما باید پلیر ویدیو (Video Player) را به گونه‌ای سفارشی‌سازی کنید که مجهز به قابلیت‌های زیر باشد:

* واترمارک داینامیک (Dynamic Watermark): پلاگین شما باید شماره موبایل یا کدملیِ کاربر لاگین‌شده را به صورت متحرک و با شفافیت کم (Opacity پایین)، روی ویدیو در حال پخش نمایش دهد. اگر کاربر با گوشی خود از روی مانیتور فیلم‌برداری کند، هویت او فاش می‌شود و این کار ریسک انتشار را به شدت کاهش می‌دهد.
* قفل کردن کلیک راست و کدهای کنسول: استفاده از کتابخانه‌های جاوا اسکریپت برای غیرفعال کردن کلیک راست و کلید F12 (Inspect Element) جهت سخت‌تر کردن دسترسی به سورس ویدیو.

## ۳. راهکارهای امنیتی اختصاصی در «اپلیکیشن موبایل» (برگ برنده شما) 📱
امنیت ویدیو در اپلیکیشن موبایل به مراتب بالاتر از وب‌سایت است. شما با چند خط کد در اپلیکیشن می‌توانید جلوی بخش عمده‌ای از سرقت محتوا را بگیرید:

* غیرفعال کردن اسکرین‌شات و ضبط صفحه (Anti-Screen Record):
* در اپلیکیشن اندروید، با فعال کردن فلگ WindowManager.LayoutParams.FLAG_SECURE در کد کاتلین/جاوا، کاربر به هیچ وجه نمی‌تواند از صفحه فیلم‌برداری کند یا اسکرین‌شات بگیرد (صفحه در فیلم سیاه می‌شود).
   * در اپلیکیشن iOS، با چک کردن رویداد isCaptured می‌توانید به محض اینکه کاربر قابلیت Screen Recording را روشن کرد، پخش ویدیو را متوقف کنید یا صفحه را تار کنید.
* عدم اجازه پخش در شبیه‌سازها (Emulator Detection): در کد اپلیکیشن شرطی بگذارید که اگر برنامه روی کامپیوتر (شبیه‌سازها مثل BlueStacks) اجرا شد، بخش ویدیوها باز نشود؛ چون در کامپیوتر دور زدن قفل‌های ضبط صفحه راحت‌تر است.

------------------------------
## ۴. تغییرات معماری در ناپ‌کامرس (تبدیل به سایت آموزشی)
برای اینکه هسته ناپ‌کامرس بتواند ساختار آموزشی بگیرد، نیازی به دستکاری دیتابیس ندارید. کافیست مفاهیم را اینگونه مپ (Map) کنید:

   1. محصول (Product) = دوره آموزشی (Course): محصول را از نوع دیجیتال و دانلودی تعریف کنید، اما به جای فایل دانلود، بعد از خرید دسترسی خریدار به «صفحه دوره» باز شود.
   2. ویژگی‌های محصول = سرفصل‌ها و دروس (Chapters & Lessons): می‌توانید یک جدول سفارشی (Custom Entity) در پلاگین خود به نام CourseLessons بسازید که به جدول Product متصل است. هر درس شامل: عنوان، مدت زمان، ویدیو (لینک VOD) و فایل ضمیمه (PDF یا تمرین) است.
   3. مدیریت دسترسی (Access Control): در صفحه دوره، پلاگین شما ابتدا چک می‌کند که آیا وضعیت سفارش این مشتری برای این محصول Paid (پرداخت شده) است یا خیر. اگر خریده بود، پلیر ویدیو لود می‌شود؛ در غیر این صورت، فقط دکمه «خرید دوره» و پیش‌نمایش (تیزر دمو) نشان داده می‌شود.

------------------------------
## یک ایده تکمیلی برای افزایش فروش پلتفرم شما: سیستم آزمون و مدرک (Quiz & Certificate)
اگر در پلاگین آموزشی خود قابلیت ساخت آزمون‌های چهارگزینه‌ای را قرار دهید و سیستم پس از قبولی کاربر، یک گواهی دیجیتال (با نام و امضای استاد) تولید کند، پلتفرم شما به یک LMS تمام‌عیار تبدیل می‌شود و کاربران تمایل بسیار بیشتری برای خرید این پکیج از شما خواهند داشت.
------------------------------
💡 پیشنهاد برای گام بعدی:
با توجه به اینکه زیرساخت ویدیو مهم‌ترین بخش کار است، آیا تمایل دارید نحوه اتصال ناپ‌کامرس به API یک سرویس VOD (مانند آروان کلاد یا کات) برای ساخت خودکار لینک‌های موقت و منقضی‌شونده ویدیو (Secure Link) را به صورت فنی بررسی کنیم؟ یا مایلید روی کدهای امنیتی اپلیکیشن (جلوگیری از ضبط صفحه) تمرکز کنیم؟

برای پیاده‌سازی این بخش، پیاده‌سازی را به دو فاز مجزا تقسیم می‌کنیم: بخش اول مربوط به بک‌اند (ناپ‌کامرس) و نحوه تولید لینک‌های امن و منقضی‌شونده از طریق سرویس‌های VOD (مانند ابر آروان) است، و بخش دوم مربوط به کدهای امنیتی اپلیکیشن موبایل (اندروید و iOS) برای جلوگیری از ضبط صفحه نمایش.
------------------------------
## بخش اول: بک‌اند ناپ‌کامرس (تولید لینک منقضی‌شونده امن - Secure Link)
در معماری امنیتی ویدیو، شما نباید لینک مستقیم و ثابت ویدیو را در پلیر سایت قرار دهید؛ چون کاربر به راحتی آن را کپی می‌کند. در عوض، باید از قابلیت لینک‌های امضاشده (Signed URLs) استفاده کنید. این لینک‌ها حاوی یک امضای دیجیتال و زمان انقضا (مثلاً فقط ۲ ساعت) هستند و تنها برای آی‌پِی همان کاربری که لاگین کرده معتبرند.
در ادامه، نمونه متد سی‌شارپ (C#) برای تولید لینک امن برای بخش ویدیو پلتفرم شما آورده شده است (این منطق بر اساس الگوریتم استاندارد سرویس‌های VOD مانند ابر آروان است):

using System;using System.Security.Cryptography;using System.Text;
public class VideoSecurityService
{
    // این کلید سکرت را باید از پنل VOD خود دریافت کرده و در تنظیمات پلاگین ذخیره کنید
    private const string SecureKey = "Your_ArvanCloud_VOD_Secure_Key"; 

    public string GenerateSecureVideoUrl(string videoPath, string userIp)
    {
        // ۱. تعیین زمان انقضای لینک (مثلاً ۲ ساعت آینده به وقت UTC)
        long expireTime = ((DateTimeOffset)DateTime.UtcNow.AddHours(2)).ToUnixTimeSeconds();

        // ۲. ساخت فرمت متنی برای رمزنگاری (شامل مسیر ویدیو، آی‌پِی کاربر و زمان انقضا)
        // ترکیب آی‌پِی باعث می‌شود اگر کاربر لینک را به شخص دیگری بدهد، برای او باز نشود
        string stringToHash = $"{SecureKey}{videoPath}{userIp}{expireTime}";

        // ۳. هش کردن متن با الگوریتم MD5 و تبدیل آن به Base64 مناسب برای URL
        string hash;
        using (var md5 = MD5.Create())
        {
            byte[] inputBytes = Encoding.UTF8.GetBytes(stringToHash);
            byte[] hashBytes = md5.ComputeHash(inputBytes);
            
            // تبدیل به فرمت استاندارد Base64 قابل استفاده در سیستم‌های ابری
            hash = Convert.ToBase64String(hashBytes)
                .Replace("+", "-")
                .Replace("/", "_")
                .Replace("=", "");
        }

        // ۴. ساخت لینک نهایی که به ویدیو پلیر فرستاده می‌شود
        string secureUrl = $"https://yourbrand.ir{videoPath}?h={hash}&e={expireTime}";
        
        return secureUrl;
    }
}

نحوه استفاده در ناپ‌کامرس:
هر زمان که کاربر خریدار وارد صفحه درس شد، کنترلر پلاگین شما آی‌پِی کاربر (_webHelper.GetCurrentIpAddress()) را گرفته، متد بالا را صدا می‌زند و لینک تولید شده را به بخش فرانت‌اند (ویجت پلیر ویدیو) پاس می‌دهد. این لینک پس از ۲ ساعت کاملاً باطل و غیرقابل استفاده می‌شود.

## بخش دوم: فرانت‌اند اپلیکیشن (کدهای امنیتی ضد ضبط صفحه)
برای اپلیکیشن موبایل مشتریان، شما باید در لایه سیستم‌عامل جلو اسکرین‌شات و اسکرین‌رکورد (Screen Recording) را بگیرید. بسته به فریم‌ورکی که اپلیکیشن شما با آن نوشته شده (Native یا Cross-Platform)، کدهای زیر را باید قرار دهید:
## ۱. اگر اپلیکیشن با فلاتر (Flutter) توسعه یافته است
از پکیج رسمی flutter_windowmanager استفاده کنید. در فایل main.dart یا صفحه پخش ویدیو، کد زیر را قرار دهید:

import 'package:flutter_windowmanager/flutter_windowmanager.dart';

@override
void initState() {
  super.initState();
  // غیرفعال کردن اسکرین‌شات و ضبط صفحه در اندروید
  disableScreenShot();
}

Future<void> disableScreenShot() async {
  await FlutterWindowManager.addFlags(FlutterWindowManager.FLAG_SECURE);
}

@override
void dispose() {
  // پس از خروج از صفحه ویدیو، وضعیت را به حالت عادی برگردانید
  FlutterWindowManager.clearFlags(FlutterWindowManager.FLAG_SECURE);
  super.dispose();
}

## ۲. اگر اپلیکیشن اندروید نیتیو (Kotlin / Java) است
در Activity مربوط به پخش ویدیو، در متد onCreate و دقیقاً قبل از متد setContentView خط زیر را اضافه کنید. این کار به اندروید دستور می‌دهد که کل محیط این اکتیویتی را در لایه کارت گرافیک رمزنگاری کند تا هیچ برنامه‌ای نتواند از آن فیلم‌بردای کند (خروجی فیلم‌های ضبط‌شده کاملاً سیاه می‌شود):

override fun onCreate(savedInstanceState: Bundle?) {
    super.onCreate(savedInstanceState)
    
    // فعال‌سازی قفل امنیتی اندروید برای این صفحه
    window.setFlags(
        WindowManager.LayoutParams.FLAG_SECURE,
        WindowManager.LayoutParams.FLAG_SECURE
    )
    
    setContentView(R.layout.activity_video_player)
}

## ۳. اگر اپلیکیشن iOS نیتیو (Swift) است
سیستم‌عامل iOS به طور پیش‌فرض فلگی شبیه به اندروید ندارد، اما یک رویداد سیستم‌عاملی به نام isCaptured ارائه می‌دهد که به محض شروع ضبط صفحه (چه از طریق Control Center و چه از طریق اتصال به مک) فعال می‌شود. شما باید این رویداد را شنود کرده و پخش ویدیو را متوقف یا صفحه را تار کنید:

import UIKitimport AVFoundation
class VideoPlayerViewController: UIViewController {
    
    var player: AVPlayer?

    override func viewDidLoad() {
        super.viewDidLoad()
        
        // ثبت شنودکننده برای تغییر وضعیت ضبط صفحه در iOS
        NotificationCenter.default.addObserver(
            self,
            selector: #selector(screenCaptureChanged),
            name: UIScreen.capturedDidChangeNotification,
            object: nil
        )
    }
    
    @objc func screenCaptureChanged() {
        if UIScreen.main.isCaptured {
            // کاربر در حال ضبط صفحه است -> ویدیو را متوقف کنید و پیغام خطا دهید
            player?.pause()
            showAlert(message: "به دلیل حفظ کپی‌رایت، ضبط صفحه نمایش مجاز نیست.")
        }
    }
}
