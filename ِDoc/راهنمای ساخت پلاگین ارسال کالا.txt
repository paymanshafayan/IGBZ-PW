برای یک پلتفرم فروشگاه‌ساز، اتصال به سرویس‌های حمل‌ونقل از نان شب واجب‌تر است. خوشبختانه در ایران اکثر شرکت‌های لجستیکی بزرگ، API رسمی برای کسب‌وکارها و توسعه‌دهندگان ارائه می‌دهند تا فرآیندهایی مثل محاسبه آنلاین هزینه ارسال، ثبت خودکار درخواست پیک و دریافت کد رهگیری مرسوله بدون دخالت دست انجام شود. [1] 
سرویس‌دهندگان خدمات ارسال کالا دارای API در ایران به سه دسته اصلی تقسیم می‌شوند:
------------------------------
## ۱. سرویس‌های درون‌شهری (پیک موتوری و وانت آنلاین)
این سرویس‌ها برای ارسال‌های سریع (زیر ۲ ساعت) داخل یک شهر استفاده می‌شوند:

* 
* اسنپ باکس (Snapp Business API): قوی‌ترین و گسترده‌ترین ناوگان درون‌شهری در ایران است. سرویس اختصاصی "اسنپ برای کسب‌وکارها" یک API پایدار ارائه می‌دهد که فروشگاه‌ساز شما می‌تواند لوکیشن مبدا و مقصد را بفرستد، قیمت زنده را بگیرد و پیک را درخواست دهد.
* تپسی باکس (Tapsi Business): تپسی نیز پنل سازمانی و API اختصاصی برای ثبت خودکار درخواست پیک موتوری و سواری جهت ارسال بسته‌ها دارد. [2] 
* الوپیک (Alopeyk API): یکی از قدیمی‌ترین‌ها در ارائه API لجستیک است. مستندات REST API بسیار تمیزی دارد و امکاناتی مثل ردیابی زنده پیک روی نقشه را برای خریدار سایت فراهم می‌کند. [1, 3] 
* میاره و زپ (Miare / Zap): این دو سرویس اختصاصاً برای لجستیک فروشگاه‌ها و رستوران‌ها طراحی شده‌اند. API آن‌ها برای ارسال‌های زمان‌بندی‌شده یا ارسال انبوه درون‌شهری فوق‌العاده بهینه است.
* 

------------------------------
## ۲. سرویس‌های برون‌شهری (پست و کوریرهای سراسری)
این سرویس‌ها برای ارسال کالا از یک شهر به شهر دیگر استفاده می‌شوند:

* 
* شرکت ملی پست ایران: پست دولتی سرویس وب‌سرویس (API) رسمی برای محاسبه نرخ بر اساس وزن/موجودی و ثبت اقلام پستی دارد، اما فرآیند دریافت مستقیم API از خود شرکت پست کمی درگیر بوروکراسی اداری و زمان‌بر است.
* تیپاکس (Tipax API): بزرگ‌ترین کوریر خصوصی کشور است. تیپاکس یک API بسیار قدرتمند دارد که هزینه ارسال را بر اساس شهر مبدا، مقصد، وزن و ابعاد به صورت زنده محاسبه کرده و امکان ثبت سفارشِ "پس‌کرایه" (پرداخت هزینه حمل توسط گیرنده) را به ناپ‌کامرس شما می‌دهد.
* چاپار و ماهکس: این دو شرکت کوریر خصوصی نیز وب‌سرویس‌های پایداری برای فروشگاه‌های اینترنتی بزرگ ارائه می‌دهند. [4] 
* 

------------------------------
## ۳. هاب‌های لجستیکی (بهترین گزینه برای فروشگاه‌ساز شما) 🌟
به عنوان یک پلتفرم فروشگاه‌ساز، کدنویسی تک‌تک این APIها (اسنپ، تیپاکس، پست و...) کار بسیار زمان‌بر و سختی است. در ایران شرکت‌هایی به نام "هاب پستی" شکل گرفته‌اند که تمام شرکت‌های بالا را در یک API واحد جمع کرده‌اند. شما فقط یک‌بار API این هاب‌ها را در ناپ‌کامرس کدنویسی می‌کنید و کاربران شما به کل خدمات ارسال ایران دسترسی پیدا می‌کنند: [5] 

* 
* تاپین (Tapin): واسط رسمی شرکت پست و یکی از بهترین هاب‌های لجستیکی است. با اتصال به API تاپین، فروشگاه شما به پست پیشتاز، پست سفارشی، تیپاکس و پیک درون‌شهری متصل می‌شود. مزیت بزرگ تاپین، امکان پرداخت در محل (COD) است؛ یعنی مشتری کالا را درب منزل تحویل می‌گیرد، پول را به پستچی می‌دهد و پست پول را به حساب فروشنده واریز می‌کند. [6] 
* پستکس (Postex): اولین هاب پستی ایران است. API پستکس خدمات شرکت پست، چاپار، تیپاکس، ماهکس، اوبار (برای بارهای سنگین) و پیک‌های درون‌شهری را به صورت یکجا ارائه می‌دهد و فرآیند مقایسه قیمت آنلاین را بسیار ساده می‌کند. [4, 5] 
* 

------------------------------
## پیشنهاد معماری برای پلاگین ناپ‌کامرس شما
با توجه به اینکه روی ناپ‌کامرس کار می‌کنید، بهترین استراتژی این است:

   1. اصلی‌ترین تمرکز خود را روی پیاده‌سازی API تاپین (Tapin) یا پستکس (Postex) بگذارید؛ چون با یک‌بار کدنویسی، هم نیاز درون‌شهری و هم برون‌شهری کاربران شما حل می‌شود و قابلیت جذاب COD (پرداخت در محل) نیز به سایت آن‌ها اضافه می‌گردد.
   2. در ناپ‌کامرس، این پلاگین را باید به عنوان یک ماژول از نوع IShippingRateComputationMethod بنویسید تا در مرحله تسویه حساب (Checkout)، وزن مرسوله و آدرس خریدار را به API هاب بفرستد و گزینه‌های ارسال (پست پیشتاز، تیپاکس و...) را همراه با قیمت دقیق به مشتری نمایش دهد.

------------------------------
💡 اگر مایل باشید، می‌توانیم مستندات فنی یا ساختار درخواست (Request/Response) یکی از این هاب‌های لجستیکی (مثل تاپین یا پستکس) را بررسی کنیم تا ببینید چه دیتایی را باید از ناپ‌کامرس برای آن‌ها ارسال کنید. کدام‌یک برای مدل کسب‌وکار شما جذاب‌تر است؟
