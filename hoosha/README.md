# هوشا

یک دستیار عامل (agent) که **روی دستگاه خودت** اجرا می‌شود، **ابزار واقعی** دارد
(خواندن و نوشتن فایل، اجرای فرمان، جستجو، وب)، **اسکیل و پلاگین** نصب می‌کند، به
**MCP server** وصل می‌شود، و با **هر پرووایدری** کار می‌کند.

نسخهٔ **۰.۲** — هستهٔ کامل و کارکننده.

---

## نصب

نیاز: **Node.js نسخهٔ ۲۰ یا بالاتر** ([nodejs.org](https://nodejs.org)).

```bash
cd hoosha
npm install
npm install -g .
hoosha
```

همین. پنجره (یا مرورگر) روی `http://127.0.0.1:7788` باز می‌شود.

بدون نصب سراسری:

```bash
npm install
node src/cli.js
```

### گزینه‌ها

```
hoosha --dir /path/to/project   پوشهٔ کاری
hoosha --port 7788              پورت
hoosha --host 0.0.0.0           شنیدن روی شبکه (پیش‌فرض فقط لوکال)
hoosha --no-open                پنجره باز نشود
```

### پنجرهٔ مستقل (اختیاری، بدون نصب چیزی)

در Chrome یا Edge روی آیکون **Install** در نوار آدرس بزن — هوشا در یک پنجرهٔ جدا بدون نوار
مرورگر باز می‌شود. برای کار روزمره همین کافی است.

پوستهٔ Electron هم در `desktop/main.js` هست (`npm i -D electron && npm run desktop`)، ولی
مسیر پیش‌فرض همان وب‌اپ است.

## پرووایدر

از فهرست استاندارد انتخاب کن، یا **سازگار با OpenAI** / **سازگار با Anthropic** را بردار و
آدرس و کلید خودت را بده. هیچ محدودیتی از سمت هوشا وجود ندارد.

| فهرست آماده | |
|---|---|
| Anthropic · OpenAI · OpenRouter · Google Gemini · DeepSeek · Groq · Mistral · xAI · Together · Fireworks · Cerebras · Azure OpenAI | ابری |
| Ollama · LM Studio · vLLM | محلی، بدون کلید |
| **سازگار با OpenAI** / **سازگار با Anthropic** | هر آدرس دلخواه — از جمله سرویس‌دهنده‌های ایرانی |
| آزمایشی داخلی | بدون کلید و بدون اینترنت، برای امتحان‌کردن خود ابزار |

دکمهٔ **«گرفتن فهرست»** مدل‌ها را از خود پرووایدر می‌خواند (هرجا `/models` داشته باشد).

## ابزارها

`read_file` · `write_file` · `edit_file` · `list_dir` · `glob` · `grep` · `bash` ·
`web_fetch` · `todo_write` · `skill` · `task` · و هر ابزاری که از **MCP** بیاید.

همه‌شان همیشه در دسترس‌اند. آنچه کنترل می‌شود **اجازه** است، نه توانایی:

| حالت | رفتار |
|---|---|
| **پلن** | فقط بررسی و خواندن. هر ابزاری که چیزی را تغییر بدهد رد می‌شود. |
| **عادی** (پیش‌فرض) | خواندن آزاد؛ نوشتن، ویرایش و اجرای فرمان **تأیید** می‌خواهند. |
| **خودکار** | همه‌چیز بدون پرسش، جز آنچه در فهرست ممنوع گذاشته‌ای. |

قاعده‌ها در `~/.hoosha/config.json` و می‌توانند پیشوندی باشند:

```json
{
  "permissions": {
    "mode": "default",
    "allow": [ "bash:git status", "bash:npm test" ],
    "deny":  [ "bash:rm -rf" ]
  }
}
```

**محدودهٔ کار:** ابزارهای فایل فقط داخل «پوشهٔ کاری» کار می‌کنند؛ مسیر بیرون از آن رد می‌شود.

## اسکیل‌ها

فرمت استاندارد `SKILL.md` — یعنی **اسکیل‌های آماده بدون تغییر نصب می‌شوند**.

```
~/.hoosha/skills/<نام>/SKILL.md              سراسری
<پروژه>/.hoosha/skills/<نام>/SKILL.md         مخصوص همین پروژه (اولویت بالاتر)
```

```markdown
---
name: fa-seo
description: بهینه‌سازی عنوان و متای فارسی
allowed-tools:
  - read_file
  - grep
---
۱. کلیدواژهٔ اصلی در ۶۰ نویسهٔ اول عنوان.
۲. متا دیسکریپشن ۱۴۰ تا ۱۵۵ نویسه.
```

فقط **نام و توضیح** اسکیل در پرامپت سیستمی می‌نشیند؛ متن کامل وقتی خوانده می‌شود که مدل
ابزار `skill` را صدا بزند. برای همین می‌شود ده‌ها اسکیل داشت بدون اینکه کانتکست پر شود.

## MCP

```json
{
  "mcpServers": {
    "files":  { "command": "npx", "args": [ "-y", "@modelcontextprotocol/server-filesystem", "." ] },
    "remote": { "url": "https://example.com/mcp", "headers": { "Authorization": "Bearer …" } }
  }
}
```

در `~/.hoosha/config.json` (سراسری) یا `<پروژه>/.hoosha/mcp.json` (پروژه‌ای).
ابزارهای هر سرور با نام `mcp__<سرور>__<ابزار>` می‌آیند تا در قواعد مجوز جدا نشانه‌پذیر باشند.
یک سرور خراب، بالا آمدن برنامه را نمی‌خواباند؛ وضعیتش در پنل **افزونه‌ها** دیده می‌شود.

## پلاگین‌ها

یک پلاگین فقط یک پوشه است:

```
plugin.json          { "name": "…", "version": "…" }
skills/<x>/SKILL.md
commands/<x>.md
.mcp.json            سرورهای MCP این پلاگین
hooks.json           هوک‌های این پلاگین
```

نصب از مخزن گیت یا مسیر محلی:

```
/plugin install owner/repo
/plugin install ./my-plugin
/plugin list
/plugin remove my-plugin
```

**نصب هیچ کدی اجرا نمی‌کند** — فقط فایل کپی می‌شود. کد وقتی اجرا می‌شود که عامل ابزاری را
صدا بزند و از دروازهٔ مجوز رد شود.

مارکت‌پلیس هم یک مخزن گیت است با فایل `marketplace.json`:

```json
{ "name": "…", "plugins": [ { "name": "seo", "source": "owner/repo", "description": "…" } ] }
```

## دستورهای اسلش

داخلی: `/help` `/clear` `/compact` `/mode` `/model` `/tools` `/skills` `/mcp` `/plugin`
`/permissions` `/cost` `/workspace` `/sessions`

دستور خودت: هر فایل مارک‌داون در `~/.hoosha/commands/` یا `<پروژه>/.hoosha/commands/`

```markdown
---
description: بازبینی یک فایل با تمرکز مشخص
---
فایل $1 را بخوان و با تمرکز روی «$2» بازبینی کن.
```

`$ARGUMENTS` کل ورودی است و `$1`،`$2`… پارامترهای جدا. در کادر ورودی با `/` فهرست
دستورها با تکمیل خودکار باز می‌شود.

## هوک‌ها

هر هوک یک فرمان پوسته است که JSON روی stdin می‌گیرد.

```json
{
  "hooks": {
    "PreToolUse":      [ { "matcher": "bash", "command": "./scripts/audit.sh" } ],
    "UserPromptSubmit":[ { "command": "echo '{\"additionalContext\":\"شاخه: main\"}'" } ]
  }
}
```

رویدادها: `SessionStart` · `UserPromptSubmit` · `PreToolUse` · `PostToolUse` · `Stop` ·
`SessionEnd`.
**توقف:** خروج با کد ۲ یا چاپ `{"decision":"block","reason":"…"}`.
**کانتکست اضافه:** چاپ `{"additionalContext":"…"}` یا هر متن خام.

هوک `PreToolUse` حتی جلوی ابزارِ *مجاز* را هم می‌گیرد — این نقطه، جای سیاست سازمانی است.

## زیرعامل و کانتکست

- **`task`**: یک نشست تازه با بودجهٔ خودش که فقط **خلاصهٔ نتیجه** را برمی‌گرداند. برای
  کاوش‌های طولانی که کانتکست اصلی را خراب می‌کنند. زیرعامل خودش `task` ندارد (جلوی بازگشت
  بی‌پایان).
- **فشرده‌سازی**: گفتگوی بلند خودکار (یا با `/compact`) به یک خلاصه تبدیل می‌شود. اگر
  خلاصه‌سازی شکست بخورد، گفتگو دست‌نخورده می‌ماند.
- **`HOOSHA.md`** در ریشهٔ پروژه، همیشه در پرامپت سیستمی می‌نشیند — همان نقش دستورالعمل
  پروژه.

## تنظیمات و داده

مسیر پیش‌فرض `~/.hoosha` است و با متغیر `HOOSHA_HOME` قابل تغییر:

```bash
HOOSHA_HOME=/path/to/config hoosha
```

```
~/.hoosha/config.json     پروفایل‌ها، کلیدها، قواعد مجوز، MCP، هوک‌ها
~/.hoosha/skills/         اسکیل‌ها
~/.hoosha/commands/       دستورهای خودت
~/.hoosha/plugins/        پلاگین‌ها
~/.hoosha/sessions/       تاریخچهٔ گفتگوها
```

> **کلید API در همین فایل ذخیره می‌شود** (دسترسی فایل روی `600` بسته می‌شود). اگر روی
> دستگاه مشترک کار می‌کنی، این را بدان.

## تست

```bash
node test/run.mjs
```

**۴۰ تست، بدون وابستگی.** ابزارها، مجوزها، اسکیل، دستور، هوک، فشرده‌سازی، هر دو پروتکل
پرووایدر (با سرور جعلی)، زیرعامل، MCP (با یک سرور MCP واقعی)، پلاگین، و حلقهٔ عامل.

قاعده‌ای که از مخزن اصلی می‌آید: **سوئیتی که بار اول سبز شود چیزی ثابت نکرده.** هر تست
اینجا با خراب‌کردن عمدی کد قرمز شده است.

## معماری

```
src/
  cli.js               ورودی خط فرمان
  server.js            سرور محلی + SSE + دستورهای داخلی
  runtime.js           سرهم‌کردن دنیا: پرووایدر، ابزار، اسکیل، پلاگین، MCP، هوک
  agent.js             حلقهٔ عامل
  tools.js             ابزارهای هسته

  skills.js            خواندن SKILL.md و ابزار skill
  mcp.js               کلاینت MCP (SDK رسمی)
  plugins.js           نصب/حذف/فعال‌سازی پلاگین و مارکت‌پلیس
  hooks.js             اجرای هوک‌ها
  commands.js          دستورهای اسلش
  subagent.js          ابزار task + فشرده‌سازی کانتکست
  config.js            تنظیمات
  session.js           نشست‌ها
  providers/           catalog · openai · anthropic · mock · sse

test/run.mjs           تست‌ها
```

تنها وابستگی: `@modelcontextprotocol/sdk` (برای MCP). بقیه‌اش Node خالی است.

## وضعیت

**هست و تست شده:** حلقهٔ عامل · ۹ ابزار داخلی + `skill` + `task` + ابزارهای MCP ·
سه حالت مجوز و قواعد پیشوندی · دروازهٔ تأیید · محدودهٔ پوشهٔ کاری · پروتکل OpenAI و
Anthropic · واکشی فهرست مدل · اسکیل (SKILL.md) · پلاگین و مارکت‌پلیس · MCP (stdio و HTTP) ·
هوک با قابلیت توقف · دستورهای اسلش داخلی و سفارشی با تکمیل خودکار · زیرعامل ·
فشرده‌سازی کانتکست · `HOOSHA.md` · نشست‌ها · شمارش توکن · رابط فارسی با استریم.

**رابط کاربری** به سبک نسخهٔ وب Claude Code است: نوار کناری نشست‌ها، ناحیهٔ گفتگو با
مارک‌داون و کارت ابزار جمع‌شونده، دیف رنگی برای ویرایش فایل، فهرست کار، دروازهٔ تأیید با
گزینهٔ «همیشه اجازه بده»، کامپوزر با انتخاب حالت و مدل، تکمیل خودکار دستورها، و تم روشن/تاریک.

**هنوز نیست:** checkpoint و rewind کامل · حالت headless (`-p`) · SDK برای تعبیه ·
elicitation و منابع MCP · اجرای سندباکس‌شدهٔ ابزارها.
