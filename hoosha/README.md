# هوشا

یک دستیار عامل (agent) که **روی دستگاه خودت** اجرا می‌شود، **ابزار واقعی** دارد
(خواندن و نوشتن فایل، اجرای فرمان، جستجو، وب) و با **هر پرووایدری** کار می‌کند.

نسخهٔ **۰.۱** — هستهٔ کارکننده. سه چیز از همین حالا واقعی است: چرخهٔ عامل، دروازهٔ تأیید،
و لایهٔ پرووایدر.

---

## نصب

نیاز: **Node.js نسخهٔ ۲۰ یا بالاتر** ([nodejs.org](https://nodejs.org)).

```bash
cd hoosha
npm install -g .
hoosha
```

همین. پنجره (یا مرورگر) روی `http://127.0.0.1:7788` باز می‌شود.

اگر نمی‌خواهی چیزی نصب کنی:

```bash
node src/cli.js
```

### گزینه‌ها

```
hoosha --dir /path/to/project   پوشهٔ کاری
hoosha --port 7788              پورت
hoosha --host 0.0.0.0           شنیدن روی شبکه (پیش‌فرض فقط لوکال)
hoosha --no-open                پنجره باز نشود
```

### نسخهٔ پنجره‌ای (Electron)

```bash
npm i -D electron
npm run desktop
```

پوستهٔ Electron فقط همان سرور محلی را در یک پنجره نشان می‌دهد؛ منطق یکی است.

## پرووایدر

از فهرست استاندارد انتخاب کن، یا **سازگار با OpenAI** / **سازگار با Anthropic** را بردار و
آدرس و کلید خودت را بده. هیچ محدودیتی از سمت هوشا وجود ندارد.

| فهرست آماده | |
|---|---|
| Anthropic · OpenAI · OpenRouter · Google Gemini · DeepSeek · Groq · Mistral · xAI · Together · Fireworks · Cerebras · Azure OpenAI | ابری |
| Ollama · LM Studio · vLLM | محلی، بدون کلید |
| **سازگار با OpenAI** / **سازگار با Anthropic** | هر آدرس دلخواه — از جمله سرویس‌دهنده‌های ایرانی |
| آزمایشی داخلی | بدون کلید و بدون اینترنت، برای امتحان‌کردن خود ابزار |

دکمهٔ **«گرفتن فهرست»** مدل‌ها را از خود پرووایدر می‌خواند (هرجا `/models` داشته باشد).

## ابزارها

`read_file` · `write_file` · `edit_file` · `list_dir` · `glob` · `grep` · `bash` ·
`web_fetch` · `todo_write`

همه‌شان همیشه در دسترس‌اند. آنچه کنترل می‌شود **اجازه** است، نه توانایی:

| حالت | رفتار |
|---|---|
| **پلن** | فقط بررسی و خواندن. هر ابزاری که چیزی را تغییر بدهد رد می‌شود. |
| **عادی** (پیش‌فرض) | خواندن آزاد؛ نوشتن، ویرایش و اجرای فرمان **تأیید** می‌خواهند. |
| **خودکار** | همه‌چیز بدون پرسش، جز آنچه در فهرست ممنوع گذاشته‌ای. |

قاعده‌ها در `~/.hoosha/config.json` قابل تنظیم‌اند و می‌توانند پیشوندی باشند:

```json
{
  "permissions": {
    "mode": "default",
    "allow": [ "bash:git status", "bash:npm test" ],
    "deny":  [ "bash:rm -rf" ]
  }
}
```

**محدودهٔ کار:** ابزارهای فایل فقط داخل «پوشهٔ کاری» کار می‌کنند؛ مسیر بیرون از آن رد می‌شود.

## تنظیمات و داده

```
~/.hoosha/config.json     پروفایل‌ها، کلیدها، قواعد مجوز
~/.hoosha/sessions/       تاریخچهٔ گفتگوها
```

> **کلید API در همین فایل ذخیره می‌شود** (دسترسی فایل روی `600` بسته می‌شود). اگر روی
> دستگاه مشترک کار می‌کنی، این را بدان.

## معماری

```
src/
  cli.js               ورودی خط فرمان
  server.js            سرور محلی + SSE + سرو رابط کاربری
  agent.js             حلقهٔ عامل (پلن ← ابزار ← نتیجه ← تکرار)
  tools.js             ابزارهای هسته
  permissions.js       موتور مجوز (پلن / عادی / خودکار)
  config.js            تنظیمات
  session.js           ذخیرهٔ نشست‌ها
  providers/
    catalog.js         فهرست استاندارد پرووایدرها
    openai.js          پروتکل سازگار با OpenAI
    anthropic.js       پروتکل سازگار با Anthropic
    mock.js            پرووایدر آزمایشی بدون شبکه
    sse.js             خوانندهٔ استریم
ui/                    رابط کاربری (فارسی، RTL، بدون فریم‌ورک)
desktop/main.js        پوستهٔ Electron
```

**بدون وابستگی زمان اجرا.** فقط Node. برای همین نصبش یک دستور است و هرجا Node باشد بالا می‌آید.

## وضعیت امروز

**کار می‌کند و تست شده:** چرخهٔ کامل عامل · هر سه حالت مجوز · دروازهٔ تأیید (اجازه/رد) ·
۹ ابزار · محدودهٔ پوشهٔ کاری · پروتکل OpenAI (شامل سرهم‌کردن JSON قطعه‌قطعهٔ tool call) ·
پروتکل Anthropic · واکشی فهرست مدل · شمارش توکن · نشست‌ها · رابط فارسی با استریم.

**هنوز نیست (گام‌های بعدی):** MCP · نصب اسکیل (`SKILL.md`) · پلاگین و مارکت‌پلیس ·
زیرعامل · هوک · فشرده‌سازی کانتکست · checkpoint و بازگشت · حالت headless.
